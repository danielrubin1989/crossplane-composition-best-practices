# Presentation

`From Terraform and Terragrunt to Crossplane_A Gradual Migration at Scale.pptx`

## Recommended viewer: Keynote on macOS

Open and present this deck with **Apple Keynote** on a Mac (File → Open, or right-click → Open With → Keynote).

The deck uses animations and transitions. Keynote plays them as designed. Other viewers may drop or change them:

- PowerPoint on Windows/Mac can render some animations differently.
- Google Slides and LibreOffice Impress skip or simplify many of them.
- Quick Look / preview panes show static slides only.

If you must use something else, step through the whole deck once beforehand and check that every animation plays.
